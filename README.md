# Perplexity - AI Chat Application

A full-stack real-time AI chat application with internet search capabilities. Built with Express.js, MongoDB, React, and Socket.io.

# Features
- User registration & login (JWT + Cookies)
- Direct dashboard access after registration (no email verification)
- Real-time chat with Socket.io
- AI-powered responses with internet search
- Protected routes for authenticated users
- Responsive Tailwind CSS UI

# Tech Stack
**Backend:** Express.js, MongoDB, Socket.io, JWT  
**Frontend:** React, Redux, Vite, Tailwind CSS

# Key Folders
- `backend/src/` - Controllers, routes, services, middleware, models, Socket.io
- `frontend/src/` - React components, Redux slices, API services, auth/chat features
